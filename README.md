# Shalx Dimmer 🟠

Free screen dimmer for Android car head units and smartphones.

## Features
- Floating, movable dimmer button
- Adjustable screen dimming (0–75%)
- Works over other apps
- Long press to reset dimming
- Remembers dimming level and button position
- Optional start on boot
- No internet connection required

## Compatibility
- Android 8.1 and above
- Android car head units
- Android smartphones

Tested on Android 8.1 and Android 15.

## Installation
1. Download the APK from GitHub Releases.
2. Install it on your Android device.
3. Allow "Display over other apps".
4. Open Shalx Dimmer and tap "Enable floating dimmer".

Some Android devices may require additional permission settings.
